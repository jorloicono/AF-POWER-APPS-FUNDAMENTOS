# Curso Power Apps: de la primera app a la automatización

Curso de 16 horas en cuatro sesiones de cuatro horas. Cada sesión tiene una presentación y dos prácticas. Las prácticas construyen dos aplicaciones que crecen durante el curso: la **Machine Ordering App** de Contoso Coffee y la **app de solicitudes de vacaciones**, construida sobre una tabla de Excel en OneDrive, que termina con un flujo de aprobación en Power Automate.

## Objetivos generales

- Conocer los fundamentos de Power Apps y su lugar en Microsoft Power Platform.
- Crear aplicaciones básicas orientadas a optimizar procesos y mejorar la productividad en la gestión de datos.
- Comprender el uso de controles, formularios y elementos visuales.
- Trabajar con orígenes de datos y lógica de negocio.
- Explorar la integración de Power Apps con Microsoft 365, Power BI y Power Automate.
- Identificar las capacidades de administración, mantenimiento y evolución de las aplicaciones.
- Aplicar automatizaciones básicas mediante flujos y procesos de aprobación.

## Requisitos

Cuenta de Microsoft 365 con Power Apps y Power Automate para conectores estándar, y acceso a OneDrive para la Empresa, Outlook y Teams. Todas las prácticas usan tablas de Excel en OneDrive como origen de datos, así que no hace falta un sitio de SharePoint ni permisos de administrador. Power BI con licencia gratuita para la parte de Power BI (Pro para compartir paneles). No se necesitan licencias premium ni Dataverse, salvo para trabajar dentro de soluciones, que es opcional.

Las fórmulas están escritas en notación española: `;` separa argumentos y `;;` encadena instrucciones. Con el navegador en inglés, usa `,` y `;`.
